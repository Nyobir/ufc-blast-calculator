# Як працює UFC Blast Calculator — покроковий розбір

## Крок 0: Вхідні дані

Користувач задає 6 параметрів:

| Параметр | Що це | Приклад |
|----------|-------|---------|
| **W** | Маса заряду в кг тротилового еквіваленту | 200 кг |
| **R** | Перпендикулярна відстань від заряду до стіни | 30 м |
| **Hc** | Висота підриву над землею | 5 м |
| **width** | Ширина фасаду будівлі | 10 м |
| **height** | Висота фасаду будівлі | 8 м |
| **step** | Крок сітки (відстань між точками) | 1 м |

---

## Крок 1: Генерація сітки точок на фасаді

**Файл:** `geometry.py` → `generate_grid()`

Фасад будівлі — це плоский прямокутник. Ми накладаємо на нього рівномірну сітку точок. Центр сітки `(0, 0)` — це точка, куди вибухова хвиля прилітає перпендикулярно (найближча точка стіни до заряду).

Для фасаду 10×8 м з кроком 1 м:
- По горизонталі: dx = −5, −4, −3, ... 0, ... +3, +4, +5
- По вертикалі: dy = −4, −3, ... 0, ... +3, +4

Це дає ~11 × 9 = 99 точок. Для кожної точки обчислюємо два геометричних параметри:

**R_alpha (похила відстань)** — реальна відстань від заряду до точки на стіні:

```
R_alpha = √(R² + dx² + dy²)
```

Точка `(0, 0)` має `R_alpha = R = 30 м`. Кутові точки — далі, бо хвиля летить навскіс.

**alpha (кут падіння)** — кут між напрямком вибухової хвилі та перпендикуляром до стіни:

```
alpha = arccos(R / R_alpha)
```

Для центральної точки `alpha = 0°` (хвиля б'є прямо в стіну). Для кутових точок кут більший — хвиля приходить навскіс, і відбивається слабше.

## Крок 2: Масштабована відстань (закон Хопкінсона-Кранца)

**Файл:** `blast_params.py` → `compute_point()`

Ключова ідея UFC 3-340-02: всі вибухи подібні, якщо масштабувати відстань на кубічний корінь маси заряду:

```
Z = R_alpha / W^(1/3)
```

Для W = 200 кг: `W^(1/3) = 5.848 кг^(1/3)`

Для центральної точки: `Z = 30 / 5.848 = 5.13 м/кг^(1/3)`

Це **масштабована відстань**. Вона дозволяє використовувати одні й ті ж графіки UFC для будь-якої маси заряду — від 1 кг до 100 000 кг.

## Крок 3: Пікове падаюче надлишковий тиск Ps0

**Файл:** `blast_params.py` рядок 121, `interpolation.py` → `Table1D.lookup()`

За масштабованою відстанню Z знаходимо **Ps0** — пікове надлишковий тиск набігаючої (ще не відбитої) хвилі. Дані оцифровані з графіка Figure 2-7 UFC 3-340-02.

Інтерполяція відбувається **в логарифмічному масштабі** (log-log), бо залежність тиску від відстані — степенева:

```python
log_result = np.interp(log(Z), log(Z_table), log(Ps0_table))
Ps0 = exp(log_result)
```

Тобто ми беремо логарифм від Z, інтерполюємо між логарифмами табличних значень, і повертаємо експоненту. Це набагато точніше, ніж лінійна інтерполяція, для даних, які змінюються на кілька порядків.

---

## Крок 4: Коефіцієнт відбиття C_alpha

**Файл:** `blast_params.py` рядок 124, `interpolation.py` → `Table2D.lookup()`

Коли вибухова хвиля вдаряється в стіну, тиск **зростає** через відбиття. Наскільки — залежить від:
1. **Ps0** — чим сильніший набігаючий тиск, тим більше підсилення
2. **alpha** — чим більший кут, тим менше відбиття (при 90° відбиття немає)

Це **двовимірна інтерполяція** з Figure 2-193 UFC. Таблиця має вигляд: для кожного рівня Ps0 є окрема крива C_alpha(angle).

Алгоритм:
1. Знайти два найближчих рівні Ps0 в таблиці: `Ps0_lo` і `Ps0_hi`
2. Для кожного рівня — лінійно інтерполювати по куту alpha → отримуємо `C_lo` і `C_hi`
3. Між рівнями Ps0 — інтерполювати в **логарифмічному масштабі**:

```python
t = (log(Ps0) - log(Ps0_lo)) / (log(Ps0_hi) - log(Ps0_lo))
C_alpha = exp((1-t) * log(C_lo) + t * log(C_hi))
```

Потім:
```
Pr_alpha = C_alpha × Ps0
```

Це **піковий відбитий тиск** — максимальний тиск, який відчує стіна в даній точці.

## Крок 5: Відбитий питомий імпульс ir_alpha

**Файл:** `blast_params.py` рядок 128

Аналогічна двовимірна інтерполяція з Figure 2-194 UFC. Таблиця дає масштабований імпульс `ir_scaled` в одиницях `кПа·мс/кг^(1/3)`.

Перетворення в реальні одиниці:
```
ir_alpha = ir_scaled × W^(1/3) / 1000
```

Ділимо на 1000, бо таблиця в мілісекундах, а нам потрібні секунди: `кПа·мс → кПа·с`.

Імпульс — це площа під кривою тиску. Фізично це "штовхок", який отримує стіна.

---

## Крок 6: Час прибуття tA та тривалість позитивної фази t0

**Файл:** `blast_params.py` рядки 132–135

Обидва параметри — одновимірна log-log інтерполяція з Figure 2-7:

```
tA = tA_scaled(Z) × W^(1/3) / 1000    [с]
t0 = t0_scaled(Z) × W^(1/3) / 1000    [с]
```

- **tA** — через скільки секунд після вибуху хвиля дістане до цієї точки
- **t0** — скільки часу тиск лишається позитивним (фаза стиснення)

## Крок 7: Параметр загасання Фрідландера b

**Файл:** `blast_params.py` → `solve_friedlander_b()`

Тепер ми знаємо Pr_alpha, t0 і ir_alpha. Хвиля описується рівнянням Фрідландера:

```
P(t) = Pr_alpha × (1 − τ) × exp(−b × τ)
```

де `τ = (t − tA) / t0` — безрозмірний час від 0 до 1.

Параметр **b** визначає, наскільки швидко тиск спадає. Якщо проінтегрувати рівняння Фрідландера аналітично, отримаємо:

```
ir = (Pr × t0) / b² × (b − 1 + exp(−b))
```

Це **трансцендентне рівняння** — його не можна розв'язати алгебраїчно. Тому використовується **метод Брента** (числовий пошук кореня на інтервалі [0.01, 50]):

```python
def residual(b):
    return (Pr * t0) / b² × (b - 1 + exp(-b)) - ir

b = brentq(residual, 0.01, 50.0)
```

Метод Брента шукає таке b, при якому `residual = 0`, тобто аналітичний імпульс точно дорівнює табличному.

## Крок 8: Векторизація (для швидкості)

**Файл:** `blast_params.py` → `compute_points_batch()`

Замість обрахунку кожної точки по черзі (повільний Python-цикл), ми робимо все одразу масивами NumPy:

1. Всі Z обчислюються одним масивом
2. Всі Ps0 — одна batch-інтерполяція
3. Всі C_alpha — одна batch 2D-інтерполяція
4. Параметр b — **векторизований метод Ньютона** замість Брента:

```python
for _ in range(100):  # ітерації Ньютона
    f  = (Pr * t0) / b² × (b - 1 + exp(-b)) - ir
    df = (Pr * t0) / b³ × (-b + 2 - (2+b)×exp(-b))
    b  = b - f/df
```

Ньютон працює з масивами і сходиться за ~10 ітерацій для всіх точок одразу. Результат: **2091 точка за ~1 мс** замість ~2 с у циклі.

## Крок 10: Клік по точці → крива Фрідландера

Коли ви клікаєте на контурному графіку, програма знаходить найближчу точку сітки і будує часову криву:

```python
t = np.linspace(tA - 0.005, tA + t0, 500)
P = Pr_alpha × (1 - τ) × exp(-b × τ)
```

Це і є форма вибухової хвилі в часі — різкий стрибок тиску при tA, потім експоненціальний спад до нуля за час t0.

## Підсумок потоку даних

```
Вхідні параметри (W, R, Hc, width, height, step)
        │
        ▼
Сітка точок на фасаді (dx, dy) → (R_alpha, alpha)
        │
        ▼
Масштабована відстань Z = R_alpha / W^(1/3)
        │
        ├──► Ps0(Z)         ← Figure 2-7, log-log 1D
        ├──► tA(Z), t0(Z)   ← Figure 2-7, log-log 1D
        │
        ▼
C_alpha(Ps0, alpha) → Pr = C_alpha × Ps0    ← Figure 2-193, 2D
ir_alpha(Ps0, alpha) × W^(1/3) / 1000       ← Figure 2-194, 2D
        │
        ▼
Розв'язок b з: ir = (Pr×t0)/b² × (b-1+exp(-b))
        │
        ▼
Контурний графік Pr(dx, dy) + крива P(t) при кліку
```
